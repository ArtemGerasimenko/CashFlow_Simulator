# CashFlow — Симуляторы потоков

Главная страница: прежний тёмно-синий неоновый дизайн, четыре карточки вертикальным списком, центрирование по горизонтали и вертикали на больших экранах, адаптивные размеры для планшетов и компьютеров. На телефонах страница начинается сверху и остаётся удобной для прокрутки.

Карточки ведут на соответствующие HTML-файлы:
- `fast-flow-super-fast-flow.html`
- `growing-flow.html`
- `vip-fast-flow.html`
- `year-flow.html`

Для GitHub Pages загрузите все файлы в корень репозитория и включите Pages для `main` / `root`.
