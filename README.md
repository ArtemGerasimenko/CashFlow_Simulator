# CashFlow — полный архив сайта

## Состав
- `index.html` — главная страница со списком симуляторов.
- `fast-flow-super-fast-flow.html` — Fast Flow / Super Fast Flow.
- `growing-flow.html` — Growing Flow.
- `vip-fast-flow.html` — VIP Fast Flow.
- `year-flow.html` — Year Flow.
- `Cumulative-Flow.html` — Cumulative Flow.

## Обновление главной страницы
Карточка **Cumulative Flow** добавлена непосредственно под **Year Flow**. Для неё использован тот же макет карточек и та же бирюзовая цветовая схема, что и у соседних симуляторов.

## Публикация на GitHub Pages
Загрузите все шесть HTML-файлов в корень репозитория. Главная страница открывается через `index.html`. Все симуляторы являются самостоятельными HTML-файлами.

## Сохранность логики
В рамках добавления карточки главной страницы исходные файлы симуляторов не редактировались. Включённый `Cumulative-Flow.html` взят из последней версии с удалённым лишним `\n` внизу. Тарифы, формулы и JavaScript симуляторов не изменялись в этой сборке.
