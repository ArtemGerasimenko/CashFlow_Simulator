# CashFlow — симуляторы потоков

Статический сайт для публикации через **GitHub Pages**.

## Состав проекта

- `index.html` — главная страница со ссылками на симуляторы.
- `fast-flow-super-fast-flow.html` — Fast Flow и Super Fast Flow.
- `growing-flow.html` — Growing Flow.
- `vip-fast-flow.html` — VIP Fast Flow.
- `year-flow.html` — Year Flow.

## Публикация на GitHub

1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое архива в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Дождитесь публикации сайта.

Главная страница открывается через `index.html`, поэтому оставьте его в корне репозитория.
