- корректность aria-labelledby / aria-describedby / aria-controls;
- наличие type у кнопок и alt у изображений;

Исправление:
- Fast Flow / Super Fast Flow: при переключении площадки на Россию динамический курс ERUB обновлялся в поле, но результат расчёта оставался рассчитанным по предыдущему курсу до следующего действия пользователя. Теперь после каждого автоматического обновления курса сразу выполняется пересчёт. Также убран дублирующий повторный пересчёт при смене календарного дня.

Тарифные таблицы, проценты, номиналы и остальные правила расчёта не менялись.

Примечание: это статическая техническая проверка кода. Она не заменяет проверку на опубликованном хостинге и проверку внешних сервисов/ссылок в реальной сети.
